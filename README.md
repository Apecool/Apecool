# 👋 Hi, I'm Apecool

Independent developer working on two tracks: **mathematical formalization** (locating concepts on four axes — axioms / analysis / algebra / logic — and letting the Lean 4 + Mathlib kernel check the proofs) and **AI-code verifiability** (an honest, reproducible study of what behavioral contracts can and cannot catch in AI-generated code).

> "It compiles" does not mean "the proof is right" — the kernel is the final judge.

## 📐 Method & principles

- **Verification over claims**: the kernel is the final judge in formalization; the golden reference checks the checker in the verifiability study
- Math history → Lean statement → proof; slow is fine, "compiles but drifts" is not
- Long-term goals: merged PRs to mathlib; understanding how AI changes the way mathematics is produced

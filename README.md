## 📐 方法与原则

- **内核最终裁判**：形式化以 kernel 检查为准，禁 sorry-laundering，语义逐行自查
- 数学史 → Lean 陈述 → 证明，宁可慢，不要「能编译但跑偏」
- 长期目标：mathlib merged PR；理解 AI 正在如何改变数学的生产方式
